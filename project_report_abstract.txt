ABSTRACT

The Campus Complaint Management System (CampusVoice) is a full-stack, database-driven web application developed to digitize and automate the grievance redressal process in educational institutions. The system replaces traditional, paper-based complaint workflows with a centralized online portal that caters to three distinct user roles: Students, Staff Officers, and Administrators. Students can register, submit complaints with file attachments, monitor status timelines, and provide satisfaction feedback. Administrators can view campus-wide statistics, assign complaints to departmental staff, and manage the entire grievance lifecycle through an interactive dashboard.

The backend is built using Python and the Flask micro-framework, supported by a relational MySQL database comprising 8 normalized tables with foreign key constraints, cascading delete rules, and check constraints to ensure referential integrity. Advanced database features including a multi-table VIEW (v_complaint_details), two automated TRIGGERS (trg_auto_assign_dept and before_complaint_update), and two STORED PROCEDURES (sp_update_complaint_status and sp_dashboard_summary) are implemented to automate business logic, logging, and real-time status management. A self-healing SQLite fallback mechanism ensures continuous availability even when the primary MySQL server is offline. The frontend is developed using HTML5, CSS3, Bootstrap 5, and vanilla JavaScript, featuring asynchronous AJAX API calls for real-time dashboard updates without page reloads. Security is enforced through Bcrypt password hashing, session-based role authentication, and parameterized SQL queries to prevent injection attacks. The system demonstrates a robust integration of full-stack development principles and advanced RDBMS concepts applied to solve a real-world administrative problem.

Keywords: Flask, MySQL, Relational Database, Triggers, Stored Procedures, AJAX, Role-Based Access Control, Bcrypt, Entity-Relationship Model, Complaint Management.
