4.1 INSTALLATION STEPS FOR THE EXECUTION OF THE PROJECT

The execution and deployment of the Campus Complaint Management System require a systematic, sequential setup of the local development environment, database engines, and runtime dependencies. The first step involves installing Python (version 3.8 or higher) from the official website and ensuring it is added to the system's global environment variables path. Once Python is established, the developer must start the relational database layer. This is achieved by installing and launching a MySQL server daemon, which typically runs locally on port 3306. Administrators can launch the MySQL service directly through utility suites like XAMPP or the standard Windows Service Manager. Following the database server startup, the developer opens a MySQL command line client and runs the schema.sql script located in the database folder of the workspace. This script compiles the database named campus_complaints and creates the 8 required tables, 2 database views, 2 triggers, and 2 stored procedures.

Once the database structure is created, the next step is installing the Python package dependencies. The developer opens a Windows command prompt or terminal window in the project's root workspace folder (C:\Users\Hp\.gemini\antigravity\scratch\campus-complaint-system\) and runs the installation command: pip install -r requirements.txt. This command prompts pip to fetch and install all external libraries, including Flask, PyMySQL, and Bcrypt, making them globally available to the application compiler. Once the libraries are successfully installed, the Flask backend is started by running the command: python app.py. The console will display a success log indicating that the development server is active and listening on the local socket address: http://127.0.0.1:5000/. Users can access the student and admin dashboard portals by opening any standard web browser and typing this local IP address into the browser's URL address bar.
